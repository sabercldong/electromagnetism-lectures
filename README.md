## 源码与编译

`src/lectures/` 保存 29 份完整 LaTeX 正文；`src/tikz/` 保存 29 份可独立编译的 TikZ 图册。正文中的原图数据自包含，配图保留可编辑的 TikZ 定义。

安装 Tectonic 后，在项目根目录运行：

```sh
# 编译第一讲
python3 scripts/compile.py --lecture 1

# 编译第一讲的独立配图册
python3 scripts/compile.py --lecture 1 --diagrams

# 编译全部正文
python3 scripts/compile.py --all
```

编译结果写入 `build/`。源稿使用 `ctexart`、Fandol 中文字体、TikZ、amsmath、esint 等；Tectonic 会按需获取依赖，首次编译需要联网。
